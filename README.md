# IntraCalc Pro - Sistema Clínico de Intradermoterapia & Farmacologia Avançada

Sistema avançado e interativo para cálculos de diluição, farmacologia estética, mesclas personalizadas e protocolos clínicos de intradermoterapia.

## 🚀 Funcionalidades
- **Cálculo de Mesclas e Diluições**: Dosagens precisas por ponto, volume total e concentrações.
- **Biblioteca Farmacológica**: Informações completas de ativos, indicações, contraindicações e compatibilidade.
- **Protocolos Pré-configurados**: Sugestões clínicas para gordura localizada, flacidez, celulite, capilar e rejuvenescimento facial.
- **Segurança & Alertas**: Verificação de volume máximo por sessão e incompatibilidades físico-químicas.
- **Exportação & Prescrição**: Geração de fichas e protocolos para prontuário.

## 🛠️ Tecnologias
- HTML5 / Vanilla JavaScript
- Tailwind CSS & FontAwesome
- Google Fonts (Inter & JetBrains Mono)
